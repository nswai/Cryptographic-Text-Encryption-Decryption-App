🔐 CryptoSpy — Нативний криптографічний додаток
Додаток побудований на базі чистого Win32 API та C++, що забезпечує максимальну швидкість роботи та нульову залежність від стороннього софту.

✨ Особливості проєкту

🚫 Сторонні бібліотеки відсутні: Уся криптографічна логіка реалізована «з нуля» за допомогою об'єктно-орієнтованого програмування та стандартної бібліотеки STL.

🇺🇦 Повна підтримка Юнікоду: Програма бездоганно працює з українським алфавітом (включаючи літери Ґ, Є, І, Ї) завдяки використанню широких символів std::wstring.

🛠️ Hex-Engine для XOR: Повністю вирішено класичну проблему появи «кракозябр» та нечитабельних символів. Зашифрований бінарний потік конвертується у безпечний текстовий формат шістнадцяткових кодів.

🔄 Інтерфейсна функція «Реверс»: Кнопка швидкої взаємодії (UX) — миттєво переносить отриманий зашифрований результат у вікно введення для зворотного дешифрування за один клік.

🪶 Екстремальна оптимізація: Додаток є повністю автономним (Portable), важить менше 100 КБ та споживає до 3 МБ оперативної пам'яті.
